# Ember Stage 7 — Run it

Requirements: Node.js 22.5 or newer.

```bash
npm start
```

Open: http://localhost:8787

No npm packages are required. The backend uses Node's built-in HTTP server and SQLite module.

Important: Stage 7 must be opened through the local server. Opening `ember-wildfire.html` directly with `file://` bypasses the backend APIs and scenario database.
