# Ember Stage 9 — run locally

1. Install Node.js 22.5 or newer.
2. Optional: copy `.env.example` to `.env` and add your own NASA FIRMS `FIRMS_MAP_KEY`.
3. In this folder run `npm start`.
4. Open `http://localhost:8787`.
5. Use **Create account** in the left panel. Passwords are hashed server-side; the browser receives an HttpOnly session cookie.
6. Saved scenarios are private to the signed-in account.

Do not open `ember-wildfire.html` directly from disk.
